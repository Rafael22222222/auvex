# Auvex

A focused, premium marketing website for Auvex — an independent digital studio building catalogues, websites, automation and AI systems for businesses.

## Positioning

The homepage leads with a concrete starter offer: a **Catalogue & Enquiry Setup** for retailers, dealers and product businesses. Broader web, app, AI, automation and creative capabilities are presented as expansion paths rather than six competing primary offers.

## Principles

- Business outcomes before technology labels
- Concept work is always labelled honestly
- No invented client logos, testimonials or metrics
- Founder-led positioning while the studio builds its case-study base
- Accessible, responsive and restrained motion

## Run locally

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

Before launch, replace placeholder contact information and the temporary Vercel metadata URL with the final Auvex domain.
